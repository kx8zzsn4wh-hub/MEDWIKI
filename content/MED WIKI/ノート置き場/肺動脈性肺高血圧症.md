このうち、特発性PAH：IPAH と遺伝性PAH：HPAH は指定難病である

＜発症年齢・性別比＞

＜リスク因子＞
　

---
# 病理・病態

＜原因＞

＜自己抗体・分子マーカー・遺伝子＞

＜病態生理＞
　肺細小動脈壁が肥厚し、内腔の狭窄が生じることでPAPが上昇。これが右心負荷の上昇、右心不全を起こす。肥厚する原因はよくわかっていない。

肺高血圧症に準拠

症候::

エコー:: [[右室拡大]]、[[推定肺動脈圧上昇]]

＜併発・合併疾患＞

# 合併症・併発症として本症がある疾患

```dataview
table without id file.link as 疾患名, tags as "タグ"
from ""
where
    contains(合併症, this.file.name)
    or contains(併発症, this.file.name)
    or any(this.file.aliases, (a) => contains(合併症, a))
    or any(this.file.aliases, (a) => contains(併発症, a))
sort tags asc
```
