# 合併症・併発症として本症がある疾患

```dataview
table without id file.link as 疾患名, tags as "タグ"
from ""
where
    contains(合併症, this.file.name)
    or contains(併発症, this.file.name)
    or any(this.file.aliases, (a) => contains(合併症, a))
    or any(this.file.aliases, (a) => contains(併発症, a))
sort tags asc
```

# 問題検索用
現在のノート名およびエイリアスが“出題内容”に含まれる問題

```dataview
table 要復習 as "要復習", 微妙 as "微妙", tags as "タグ", 出題内容 as "出題内容"
from ""
where (contains(tags, "国試") or contains(tags, "CBT") or contains(tags, "総合試験") or contains(tags, "PBL") or contains(tags, "オリジナル"))
and 出題内容
and any(出題内容, (d) =>
    d = this.file.name
    or (this.aliases and any(this.aliases, (a) => d = a))
)
sort tag desc
```
