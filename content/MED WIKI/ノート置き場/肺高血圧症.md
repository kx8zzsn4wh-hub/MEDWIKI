# 病型分類

### 肺高血圧症臨床分類（2022）
＜第一群＞
・[[肺動脈性肺高血圧症]]：PAH
　・特発性PAH
　・遺伝性PAH
　・薬物・毒物誘発性PAH
　・各種疾患に伴うPAH
　・肺静脈閉塞症：PVOD/肺毛細血管腫症：PCHを伴うPAH
　・新生児遷延性肺高血圧症：PPHN
＜第二群＞
・左心性心疾患に伴う肺高血圧症
　・左心不全
　・弁膜疾患
　・後毛細血管性PHに至る先天性/後天性心血管疾患
＜第三群＞
・肺疾患及び/または低酸素血症に伴う肺高血圧症
　・閉塞性肺疾患または肺気腫
　・拘束性肺疾患
　・拘束性/閉塞性の混合性肺疾患
　・低換気症候群
　・肺疾患を伴わない低酸素血症
　・肺の発育障害
＜第四群＞
・肺動脈閉塞に伴う肺高血圧症
　・慢性血栓塞栓性肺高血圧症：CTEPH
　・その他の肺動脈閉塞
＜第五群＞
・詳細不明及び/または多因子が関連する肺高血圧症
　・慢性腎不全

肺高血圧症に共通のもの。詳しくは各病型を参照。

＜症状＞
症候:: [[呼吸困難]]（労作時）、[[易疲労感]]、[[失神]]　　右心不全による[[頸静脈怒張]]、[[肝腫大]]、[[腹水]]、[[下腿浮腫]]　　低酸素血症による[[チアノーゼ]]、[[ばち指]]など

# 合併症・併発症として本症がある疾患

```dataview
table without id file.link as 疾患名, tags as "タグ"
from ""
where
    contains(合併症, this.file.name)
    or contains(併発症, this.file.name)
    or any(this.file.aliases, (a) => contains(合併症, a))
    or any(this.file.aliases, (a) => contains(併発症, a))
sort tags asc
```
